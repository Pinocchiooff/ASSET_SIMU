# CC0 starter pack

This folder is the staging destination for `python3 scripts/fetch_polyhaven_pack.py`.
The script queries Poly Haven's official public API for a small drone-simulator set:

- PBR materials: aerial grass/rock, asphalt, mud, forest ground, coastal rocks
- Model: dry boulder
- HDRI: autumn field sky

Poly Haven publishes its assets as CC0, but verify the asset page and generated `download-report.json` before redistribution. Staged source files are not automatically runtime assets; validate formats and optimize them before placing files in `public/assets/`.
